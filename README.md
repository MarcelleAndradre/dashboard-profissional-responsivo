# Dashboard Profissional Responsivo

Página web responsiva que apresenta o perfil profissional e acadêmico de Marcelle Andrade, com formação, competências, projetos e formas de contato.

Projeto da **Atividade Prática IV** da disciplina de Desenvolvimento Front-End, do curso de Engenharia de Software do Centro Universitário FAMETRO (professor Jean da Silva Holguim).

## Tecnologias utilizadas

- HTML5 semântico (`header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS3 (variáveis, cores, tipografia, espaçamentos, bordas, sombras e estados de interação)
- Flexbox para toda a organização do layout
- Media Queries para tablet (até 900px) e smartphone (até 600px)

## Principais funcionalidades

- Cabeçalho fixo com nome, área de atuação e menu de navegação por âncoras
- Indicadores de resultados em destaque logo no início
- Seções Sobre, Formação e experiência, Competências, Projetos e Contato
- Cards que se reorganizam conforme o tamanho da tela
- Foco visível para navegação por teclado e respeito à preferência de movimento reduzido
